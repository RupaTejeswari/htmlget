  • To create animation in css, we need two main concepts they are:
    1. Keyframes

Animation properties

To apply your @keyframes to an HTML element, you attach specific animation sub-properties:
animation-name: The name of your @keyframes (e.g., slideAndColor).
animation-duration: How long one cycle takes (e.g., 3s or 500ms).
animation-timing-function: The speed curve (e.g., linear, ease, ease-in-out).
animation-delay: Waiting time before the animation starts (e.g., 1s).
animation-iteration-count: Number of times it plays (e.g., 3 or infinite).
animation-direction: Plays forward, backward, or alternates (normal, reverse, alternate).
animation-fill-mode: Styles applied before/after it plays (none, forwards, backwards, both).
animation-play-state: Pauses or runs the animation (running, paused).
The Shorthand SyntaxInstead of writing out every individual sub-property, you can compress them into a single, clean animation property line. Order: name | duration | timing-function | delay | iteration-count | direction | fill-mode

Keyframes

keyframes are used to define the stage of an animation.
Each keyframe describe how the element should look at a specific moment during the animation.
→use percentage values(like 0% to 100%) or keywords(like from and to) to specify the beginning and end of the animation

css syntax

→type 1

  @keyframes slideAndColor {
  0% {
    transform: translateX(0);
    background-color: red;
  }
  50% {
    transform: translateX(100px);
    background-color: yellow;
  }
  100% {
    transform: translateX(200px);
    background-color: green;
  }
}

→type 2

 @keyframes myAnimation {
  from {
    background-color: red;
}
  to {
    background-color: yellow;
}
}

pseudo class

A CSS pseudo-class is a keyword added to a selector that styles an HTML element based on its special state or user interaction.

:hover: Triggers when a cursor moves over an element.
:focus: Triggers when an element receives focus, like a text field or link clicked via keyboard.
:active: Triggers while an element is being clicked or activated.
:visited: Targets links the browser history shows have been clicked
:first-child: Selects the first child element inside its parent container.
:last-child: Selects the absolute last child inside its parent container.
:nth-child(n): Selects children using numbers, keywords (even, odd), or functional formulas (e.g., 3n+1).
:first-of-type: Selects the first child element matching that specific tag name.
:only-child: Selects an element if it is the solitary child in that container.
:checked: Targets activated checkboxes, radio inputs, or option elements.
:disabled: Targets fields that are currently non-interactive.

pseudo elements

A CSS pseudo-element is a keyword added to a selector that lets you style a specific, abstract part of an HTML element without altering the actual HTML markup.

::before: Inserts a virtual child element at the very beginning of the target.
::after: Inserts a virtual child element at the very end of the target.
::first-letter: Targets the first letter of a block container text to build stylized drop caps.
::first-line: Styles only the first rendered line of text, automatically updating if the viewport resizes.
::placeholder: Customizes the text styling inside structural input or textarea placeholders.
::selection: Alters the background highlighting and color when text is active/highlighted by a user's cursor.
::marker: Targets the bullet points of unordered lists or numeric indicators on ordered lists
